\subsection{Objective of the experiment}

In this section a symmetric key obtained from the execution
of BB84 qkd protocol in \cref{sec:bb84} is used to encrypt a word,
using the OTP protocol.
Later, an encrypted message is exchanged between two computers connected to the
same network, assuming their mutual authentication. Notice that the
key used in the
second step was not obtained using the setup of
\cref{sec:bb84}, but using a
real industry-grade setup present in INRiM headquarters.
