\subsection{Setup description}
The encryption and the communication were realized digitally, using
mainly a Python Jupyter notebook to sketch the codes and then
pure Python files to have a more organized structure.
The following libraries were included during the full run:
\begin{itemize}
  \item \textbf{os}: Provides operating system functionality, such as
    accessing environment variables, working with files and
    directories, and interacting with the underlying operating system.
  \item \textbf{socket}: Implements the Berkeley sockets API,
    enabling network communication over protocols such as TCP and
    UDP. It is used to create, configure, and manage client and
    server network connections.
\end{itemize}
